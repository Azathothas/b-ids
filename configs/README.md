# configs

Generated client configuration and detection rules, one directory per
profile, produced from the corpus by `b-ids-corpus publish`.

⛔ **A snippet exists only where the support matrix records the pair as
emittable.** Where it records a hole, this tree carries a file naming
the hole, the stack, and the file and line it was read at, and no
snippet at all. A snippet that silently approximated would produce a
client that is almost right, which is more distinguishing than an
honestly old one.

⚠ **A cell comes from a run and a hole comes from a reading.**
`formats/formats.md` carries the matrix itself.

This build generated **24** snippet(s) and **48** hole
file(s), over these stacks:

- `b-ids-emit`
- `rustls`
- `h2`
- `impit`
- `utls`
- `detection`

⛔ **No digest artefact is here.** The corpus holds no digest, and a
value computed at generation time is the one thing this project's
routes were ruled not to carry.
