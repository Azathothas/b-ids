# Archived work records

The repository's initial 107 implementation records are complete and retained
under [`../history/todo/`](../history/todo/). They are historical evidence, not
a current backlog or operating queue.

The archive contains:

- `INDEX.md`: all entries and mechanically checked status totals;
- `PROGRESS.md`: the final session snapshot;
- `RULES.md`: the rules used while the records were active;
- category files: each problem, decision, implementation, and acceptance
  evidence.

`scripts/common/check-record.sh` and `check-record.ps1` verify that every entry
is indexed, every status agrees, all 107 entries are `done`, and all archive
links resolve. A new unresolved item must not be inserted into this closed
record or described as completed. Track it in the current change or create a
new, explicitly current work record with its own index and validation contract.
